## 🚀 Deployment
This project was successfully deployed on **AWS** using the following stack:
* **Hosting:** Amazon S3 (Static Website Hosting)
* **CDN:** Amazon CloudFront (for SSL and caching)
* **DNS:** Route 53
* **Backend (if applicable):** Hosted on EC2 with an Nginx reverse proxy.
